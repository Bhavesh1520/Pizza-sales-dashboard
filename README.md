# Pizza-Sales-Dashboard (Interactive Dashboard using MS Excel)
1.Project objective

To analyze pizza sales data to identify key trends, best-selling products, and peak order times.

 2.Short Description

 The Pizza Sales Dashboard provides comprehensive insights into pizza sales performance, helping to identify key trends, best-selling items, customer preferences, and revenue patterns. This project visualizes sales data to support data-driven business decisions for maximizing profit and operational efficiency.

 3.Key Insights

 Busiest Days: Friday and Saturday evenings have the highest order volume.
 
 Top Time Slot: Peak orders occur between 12 PM – 1 PM and 5 PM – 8 PM.

 Best Sellers: Classic Deluxe and Chicken pizzas generate the most revenue.

Worst Seller: The Brie Carre pizza shows the lowest performance.

Top Category: Classic pizzas contribute the highest total sales.

Size Impact: Large pizzas dominate overall sales and revenue.

4.Tools and Technologies

Microsoft Excel – for data cleaning, analysis, and interactive dashboard creation

Pivot Tables & Pivot Charts – to summarize and visualize key sales metrics

Excel Formulas & Functions – including LOOKUPs, IF, SUMIFS, and AVERAGEIFS for data computation

Data Validation & Slicers – for filtering and dynamic dashboard interactivity

Conditional Formatting – to highlight performance trends and KPIs visually

Data Visualization – charts, graphs, and KPIs designed for clear business insights
